You can modify this file while the fitting is running.
After an MCMC chunk has finished being calculated, this file is re-read.
All lines containing a valid command cause the creation of specific result files/plots.
All lines after the first line that starts with `#` are ignored.
If the file is empty, or if a line starting with `#` appears before any command lines, no results are generated.
